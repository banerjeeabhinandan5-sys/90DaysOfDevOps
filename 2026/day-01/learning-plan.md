# 🚀 My 90-Day DevOps Learning Plan

## 📖 My Understanding

DevOps is the practice of combining development and operations to build, test, and deploy software faster through automation and collaboration. Cloud Engineering focuses on building and managing applications on cloud platforms like AWS.

## 🎯 Why I'm Learning DevOps & Cloud

* Build in-demand technical skills.
* Learn automation and cloud technologies.
* Gain hands-on experience with real projects.
* Prepare for a DevOps/Cloud Engineer career.

## 🌟 My Goal

By the end of 90 days, I want to:

* Learn Linux, Git, Docker, Kubernetes, and AWS.
* Understand CI/CD and Infrastructure as Code.
* Build and publish DevOps projects on GitHub.
* Be ready for entry-level DevOps opportunities.

## 📅 90-Day Roadmap

* **Month 1:** Linux, Git, Networking, Cloud Basics
* **Month 2:** Docker, CI/CD, AWS
* **Month 3:** Kubernetes, Terraform, Final Projects

## ✅ Daily Consistency

* Study **1–2 hours** every day.
* Practice hands-on daily.
* Push code to GitHub regularly.
* Review and track progress each week.

**Goal:** Learn consistently, build projects, and become job-ready in DevOps and Cloud Engineering.
